# مذكرتي 📝

تطبيق ملاحظات عربي (RTL) يعمل بدون إنترنت، وبياناتك بتتخزن على جهازك فقط.

## المميزات
- إضافة وتعديل الملاحظات مع **حفظ تلقائي**
- **بحث** سريع (بيتجاهل التشكيل والفروق بين أ/إ/ا وى/ي)
- **تثبيت** الملاحظات المهمة 📌
- **7 ألوان** للملاحظات + **وسوم** للتصنيف
- **وضع داكن** تلقائي أو يدوي
- **سلة محذوفات** مع زر تراجع
- **مشاركة** الملاحظة
- **تصدير/استيراد** نسخة احتياطية (JSON)
- يشتغل كـ PWA (تثبيت من المتصفح) أو كتطبيق أندرويد APK

## الطريقة 1: APK بدون تثبيت أي حاجة (GitHub Actions) ⭐
1. اعمل حساب على github.com وأنشئ مستودع جديد (Repository).
2. ارفع كل ملفات المجلد ده فيه (بما فيهم مجلد `.github`).
3. ادخل تبويب **Actions** ← **Build Android APK** ← **Run workflow**.
4. بعد ~5 دقايق، افتح التشغيل ونزّل **mozakera-apk** من قسم Artifacts.
5. فك الضغط وثبّت `app-debug.apk` على موبايلك (فعّل "التثبيت من مصادر غير معروفة").

## الطريقة 2: البناء على جهازك
المطلوب: Node 20+ وJDK 21 وAndroid Studio (أو Android SDK).

```bash
npm install
npx cap add android
npm run android:apk
```
الملف بيطلع في: `android/app/build/outputs/apk/debug/app-debug.apk`

## الطريقة 3: PWA بدون APK
ارفع مجلد `www` على أي استضافة HTTPS مجانية (Netlify / GitHub Pages / Cloudflare Pages)، وافتح الرابط من كروم على الموبايل ← القائمة ← **تثبيت التطبيق**.

## ملاحظة للنشر على Google Play
الـ APK الناتج هنا (debug) مناسب للتجربة والتثبيت المباشر. للنشر على المتجر محتاج نسخة release موقّعة بمفتاحك الخاص (AAB).
